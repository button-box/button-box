# Button Box enclosure

Printable enclosures live under [hardware/models/](../models/README.md). Each
model is a folder with its own STLs and BOM. Do not add unnamed
`button-box-enclosure-*.stl` files here.

**Default / canon model:** [`us`](../models/us/) (192 x 120 mm).

| Model | Top | Bottom |
| --- | --- | --- |
| `us` (default) | [top.stl](../models/us/enclosure/top.stl) | [bottom.stl](../models/us/enclosure/bottom.stl) |
| `eu-el001` | [top.stl](../models/eu-el001/enclosure/top.stl) | [bottom.stl](../models/eu-el001/enclosure/bottom.stl) |

Old links to `hardware/enclosure/button-box-enclosure-top.stl` and
`button-box-enclosure-bottom.stl` were a single overwritten pair. Those
filenames are retired so a path always includes a model id.

To add a third model, open a pull request that adds
`hardware/models/<model-id>/` — see [how to add a model](../models/README.md).
