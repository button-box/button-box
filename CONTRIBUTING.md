# Contributing

This project welcomes focused, respectful contributions that improve the
screen-free Message Box experience.

## Before opening a change

1. Keep behavior changes small and explain the user-facing effect.
2. Add or update tests for changed behavior.
3. Run `make check`.
4. Confirm the diff contains no secrets, personal data, recordings, device
   state, or customer information.
5. Clearly separate repository-test evidence from physical Pi validation.

## Privacy boundary

Use synthetic identifiers in tests and documentation. Never submit real phone
numbers, JIDs, Wi-Fi names or passwords, authentication stores, NFC UIDs,
message content, recordings, private addresses, or production logs. Security
reports must follow `SECURITY.md`, not a public issue.

## Collaboration

Be specific, kind, and evidence-based. Critique code and decisions rather than
people. Harassment, discrimination, threats, doxxing, sexualized conduct, and
publication of another person's private information are not acceptable.
Maintainers may edit, hide, or reject contributions that violate these rules.

## Authorship

When promoting work from the private development repository, preserve the
original author's credit in the candidate commit message and update
`AUTHORS.md` when appropriate. Do not import the private repository's history.
