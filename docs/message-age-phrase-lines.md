# Message age phrase lines

The script for the message age phrases: 12 phrases in 8 voices, 96 clips, all in
English. Each voice says the line in its own character. Rendered on 16 October
2026 with ElevenLabs `eleven_v3`, each pack's voice id and post chain, then
normalized to -16 LUFS (48 kHz, 16-bit mono PCM), like the other voice lines.
Seconds include each pack's lead and tail (DJ includes its 1 s music bed).
Every take was checked by transcription; retakes use the seed shown.

The box chooses the phrase with `messagebox/message_age.py`; see
`docs/architecture.md`.
