## Button Box v0.3.11

### New
- **Announce messages with the voice.** You can turn this on in Sound & modes. The box then says its voice's "A message for you!" line before each message. It is off by default and silent during quiet time.
- **A tap when you hold for an update.** The box plays a short tap sound when you start holding the button for an update.

### Fixed
- The box says "I'm online and ready" only after it was really offline for 10 minutes or more, and at most once an hour.
- After you change the voice, the new-card line uses the new voice right away.
- When a family reaction card is sent, the box says it once.

All changes are in the box application. The fixed update controller is unchanged, so no box needs attended maintenance for this release.
