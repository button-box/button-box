# v0.1.0

Button Box sends and receives WhatsApp voice messages through a physical button
and a caregiver dashboard. This release promotes the RC.3 application code with
no additional features or fixes.

Tested on Raspberry Pi 4.

## Included

- Voice recording, playback review and sending to approved recipients.
- Incoming voice-message playback and audio from ordinary videos.
- Recently played history, replay queue and replies to the recently played sender.
- Optional NFC cards for recipient selection.
- Caregiver controls for recipients, sounds, quiet hours and message activity.
- Startup recovery and bounded updates with rollback.

Circular video notes are not supported.

## Install or update

Download `button-box-v0.1.0-device-source.tar.gz`, `manifest.json`,
`installed-files.sha256` and `SHA256SUMS` from this release. Verify checksums
before extracting and compare installed files against the manifest afterward.

For a fresh Raspberry Pi 4 with Raspberry Pi OS Lite 64-bit based on Debian 13,
follow [installation](../installation.md). For an existing installation, follow
[bounded updates](../bounded-updates.md) and retain the rollback backup.

The dashboard is intended for the household network; do not expose it publicly.
