## Button Box v0.3.10

### New
- **The box asks again for an update.** If nobody holds the button after the owner taps Install, the box asks once more 40 seconds later.
- **The box says "Got it!" after the hold.** It says "Got it! I'm installing the update now." before the update starts, or "Got it! Automatic updates are on." when you turn on automatic updates.

### Fixed
- After the owner taps Install or turns on automatic updates, the update ask now plays even when the box is muted.
- A message read aloud after its cue no longer goes silent after the first syllable.
- The box checks recordings that the Cloud already holds much less often and waits when the Cloud asks it to slow down.

All changes are in the box application. The fixed update controller is unchanged, so no box needs attended maintenance for this release.
