# v0.1.0-rc.2 — household feedback candidate

This source prerelease builds on `v0.1.0-rc.1` for a single-unit household
trial. It is not a fleet release, bootable image, merge decision, or per-unit
hardware certificate.

## Included behavior

- Refreshed household dashboard styling and navigation, with an honest
  unassigned state when no durable box identity is present.
- Recipient naming and rename support, including group-name recovery from
  read-only WhatsApp metadata and bounded retry behavior.
- A startup-ready cue and a recording-ready cue for the physical-button flow.
- Continuous WhatsApp synchronization during read-only media downloads so
  closely following messages are not lost in a disconnect window.

## Provenance

The candidate is composed from current `main` plus the reviewed heads for the
dashboard refresh, recipient identification, startup/recording cues, and
continuous synchronization. The candidate manifest records the exact final
commit and installed-file hashes; those are authoritative for installation.

## Installation and rollback boundary

Before updating an existing box, record its exact installed-file hashes and
make a private, permission-preserving backup of the installed program and
service files. Keep settings, contacts, NFC mappings, messages, recordings,
and the WhatsApp session in place. Stop Button Box services, install the
candidate, verify the manifest, then restart the same services.

Rollback restores only the backed-up program and service files, reloads
systemd, and restarts the previously active services. It must not replace or
remove private runtime state. Verify the rollback commands against the backup
inventory before relying on them.

## Verification limits

- Repository tests, syntax checks, lint, archive checksums, installed-file
  hashes, service health, and dashboard reachability are software evidence.
- They do not prove audible cues, microphone quality, physical button or NFC
  behavior, correct household routing, successful WhatsApp delivery, or cold
  reboot recovery.
- No synthetic customer message should be sent merely to validate this
  candidate. Physical and end-to-end acceptance remains a separate attended
  check on the named unit.
- The dashboard has no login and remains household-network-only; do not expose
  it publicly.
