## Button Box v0.3.18

### New
- **Support for a built-in I²S microphone.** Boxes built with an I²S microphone (for example the INMP441) can now record. The box turns the microphone on at start-up. It does not change the boot configuration.
- **Safe microphone changes.** When a box changes between a USB microphone and an I²S microphone, the update checks that the new microphone works before the box keeps the update. If the check fails, the box goes back to the last working version.

### Fixed
- If an I²S microphone is slow or missing at start-up, the button and playback still work. Only recording waits for the microphone.

Boxes with a USB microphone see no change.
